# SD 卡准备说明

第一阶段的数据源是 SD 卡里的 `/sdcard/ecg.bin`。本目录是**拷卡内容**，把这里的文件拷到卡根目录即可。

---

## 一、卡必须满足的条件（硬性）

| 项 | 要求 | 依据 |
|---|---|---|
| 文件系统 | **FAT32**（FAT16 也可，但没必要） | ESP-IDF v6.1 的 FATFS |
| **不能用 exFAT** | 🛑 | `components/fatfs/src/ffconf.h:294` → `#define FF_FS_EXFAT 0`，**硬编码 0，Kconfig 里连开关都没有**。要用 exFAT 得改 IDF 源码，不做 |
| **不能用 NTFS** | 🛑 | FATFS 不支持 |
| 卡类型 | **SDHC，≤32 GB** | SDXC（>32 GB）出厂默认 exFAT ⇒ 直接挂不上 |
| 分区表 | **MBR**，单主分区 | SD 卡标准；Windows 格式化可移动介质默认就是 MBR |
| 扇区大小 | **512 B** | `ffconf.h:252` `FF_SS_SDCARD = 512` |
| 卷标 / 簇大小 | 随便 / 默认 | 不影响 |

### 容量根本不是考量

主演示文件 **105,964 B（103.5 KB）**，回放需持续读速 **26.5 KB/s**（500 Hz × 59 B/帧）。

⇒ **2 GB 的卡都够用两万倍。** 别为容量买大卡，大卡反而有「出厂 exFAT、Windows 不给格 FAT32」的麻烦。

### Windows 实操

1. 卡插电脑，确认容量 **≤32 GB**（卡面标识 `SDHC` 可以，`SDXC` 不行）
2. 右键 → 格式化 → 文件系统选 **FAT32** → 分配单元大小**默认** → 勾「快速格式化」
3. 把本目录的 `ecg.bin` 拷到卡**根目录**（不是子目录）
4. 安全弹出

**如果手上只有 64 / 128 GB 的卡**：Windows 原生格式化在 >32 GB 时**不提供 FAT32 选项**。要用 Rufus 或 DiskGenius 强格 FAT32。**不建议**——去买张 8 GB 或 16 GB 的卡更省事，也避免大卡格 FAT32 的簇大小异常风险。

## 三、帧结构（S1 / S2 实现依据）

```
AA 55 | TYPE(1) | LEN(2, LE) | PAYLOAD(LEN) | CRC8(1)
帧总长 = 6 + LEN
CRC8：多项式 0x07、初值 0x00，范围 = TYPE + LEN + PAYLOAD
```

**已用 4185 帧实测验证**：

| LEN | 帧总长 | 样本数 N | 文件字节验证 |
|---|---|---|---|
| 52 | 58 | 25（无 STA，v1.1 旧帧） | 参考工程 `frameSize = 58` 即此 |
| **53** | **59** | 25 | 1796 × 59 = 105,964 ✓ 精确整除 |
| 103 | 109 | 50（双通道，块布局不交错） | 71 × 109 = 7,739 ✓ 精确整除 |

🛑 **严禁按固定 58 字节硬切** —— 只在 LEN=52 下成立，LEN=53 会每帧错 1 字节、LEN=103 立刻全错。

**样本数**：`N = (LEN − 3) / 2`（LEN 奇数，含 STA）；`N = (LEN − 2) / 2`（LEN 偶数）。

**STA 位**：`bit0` mode / `bit1` notch / `bit2` channel / `bit3` raw853 / `bit4` LOD。

## 四、换文件测试的方法

卡上**只认 `ecg.bin`** 这一个文件名（需求定稿：固定名，再存覆盖）。要测别的文件：

1. 把卡上现有 `ecg.bin` 改名（如 `ecg.bin.bak`）
2. 把目标文件改名为 `ecg.bin`
3. 插卡上电

⚠ 文件放在**根目录**，不是子目录。第一阶段不做文件列表页。

## 五、两个常见故障的排查顺序

| 现象 | 首先查这个 |
|---|---|
| 挂载失败，日志报 `ESP_ERR_NOT_FOUND` / `no filesystem` | 卡是不是 exFAT（`>32 GB` 的大概率是）。换 ≤32 GB 卡重格 FAT32 |
| 挂载成功但屏是黑的 | 不是卡的问题——看 CH422G 是不是写了 `0x0A`。那个值会关背光（`bit2=0`），正确值是 `0x0E` |
| 打开文件成功但一帧都解不出来 | 文件名是不是 `ecg.bin`、在不在根目录、是不是按 58 硬切了 |
