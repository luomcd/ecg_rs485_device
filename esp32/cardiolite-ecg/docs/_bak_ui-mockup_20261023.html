怎么试：① 短按第九个按钮「回放」→ 开始播放，再按暂停 / 继续；② 按住它 1.5 秒 → 弹删除确认；③ 切到「回放 · 无数据」→ 第九个按钮置灰；④ 切到「实时 · 第二阶段」→ 前八个按钮全部可用，点「开始」后第九个按钮变「记录」，再点开始计时；⑤ 顶部「配色」可在 浅色纸 / 黑底白波 / 黑底荧光绿 之间实时切换。
说明：第一阶段（回放）下 采集 / 模式 / 陷波 / 通道 四个按钮灰显不可点 —— 回放没有采集端，这三个参数无从改动，这是刻意设计，不是缺陷。记录功能是第二阶段的，此处仅用于确认界面形态。
