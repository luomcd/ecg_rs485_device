| 6 | 触摸复位 | **GPIO4**（BSP 内部处理） | 原理图 + 厂家 demo | 与 SD/RGB 引脚无冲突（`app_config.h` 已注明） |
| 7 | IO 扩展 | **CH422G**，I2C **0x24 写 / 0x38 读** | `CH422DS1_CN.pdf` + 原理图 | 实测读写（S1 阶段） |
| 8 | CH422G 位映射 | **bit1=CTP_RST / bit2=LCD_BL / bit3=LCD_RST / bit4=SD_CS** | 原理图 + `CH422DS1_CN.pdf` | ⚠ **不是照抄文档，是实测定的**：写 `0x0E` 后「SD 挂载成功 + 触摸可用 + 背光正常」三件事同时成立（S1）。厂家 demo 用的 `0x0A` 会关背光（bit2=0） |

| 11 | 背光 | CH422G **bit2**，1=亮 | 原理图 | 实测 |
| 12 | 原生 USB | **GPIO19/20**（USB-Serial-JTAG） | `esp32-s3_datasheet_cn.pdf` | 串口 **COM35** 实测可用 |
| 13 | Flash / PSRAM | **16 MB QIO / 8 MB OCT PSRAM** | `Esp32-s3-wroom-1_wroom-1u_datasheet_cn.pdf` + 模组丝印 | `esp_psram: Found 8MB PSRAM device` 实测 |
| 14 | 安全熔丝 | Secure Boot / Flash Encryption 均 **Disabled** | — | `espefuse` 实读，efuse 干净 |

## 2. 时序 / 性能事实与出处

| 事实 | 值 | 出处 | 验证方式 |
|---|---|---|---|
| 抗撕裂模式 | **TRIPLE_PARTIAL** | `esp_lv_adapter_display.h:74` 硬编码，非配置项 | 实测 `frame buffers: 3` ⇒ framebuffer 占 **2,304,000 B** |
| LVGL 任务核 | **Core 0** | `esp_lv_adapter_config_t.task_core_id`（默认 `-1` = 不指定） | 在 `lv_timer` 回调里读 `xPortGetCoreID()` 实测为 0 |
| 任务优先级 | LVGL **6** / 生产者 5 / 消费者 3 | `esp_lv_adapter.h:103` | 实测运行时确认 |
| pclk 与帧率关系 | 16 MHz → 14.1 FPS（gain5）；24 MHz → **11.6** | — | 实测；原因是面板经 LCD_CAM 持续从 PSRAM 读 framebuffer，与 CPU 抢同一块 PSRAM |
| 帧率对增益敏感 | gain5 **14.1** / gain20 **9.7** | — | 实测（详见 S7 报告 §6.15）。竖线长度 ∝ 波形高度 |
| SD 时钟 | 20 MHz → 降到 **10 MHz** | 本项目决定 | 20 MHz 下多次出现 `0x109/0x103/0x106` 交替（接触/信号临界）；实测降频**未根治**，最终判为接触问题 |

## 3. 两条"别照抄厂家"的教训

1. 🛑 **CH422G 的 `0x0A` 会关背光**（bit2=0）。厂家 demo `03_SD_Test/sd_card.c:94` 用的是
   `0x0A`，直接照抄会得到「SD 能挂但屏黑」。本项目用 `0x0E`。
2. 🛑 **`SDSPI_DEVICE_CONFIG_DEFAULT()` 的 `gpio_cs` 默认是 `GPIO_NUM_13`**
   （`sdspi_host.h:101`），而 GPIO13 是本板 MISO。不显式改成 `SDSPI_SLOT_NO_CS`
   会把 MISO 当片选驱动，挂载失败且**报错信息完全指不到引脚**。
