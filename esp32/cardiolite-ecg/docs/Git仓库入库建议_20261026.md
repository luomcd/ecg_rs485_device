## 0. 先说一个**必须先决定**的结构问题

`cardiolite-ecg/CMakeLists.txt` 里有这一行：

```cmake
set(EXTRA_COMPONENT_DIRS "${CMAKE_CURRENT_LIST_DIR}/../bsp_ws_lcd5")
```

也就是说 **`bsp_ws_lcd5` 在 app 目录之外**，而 `main` 又 `REQUIRES bsp_ws_lcd5`。

⇒ **如果仓库根设成 `cardiolite-ecg/`，别人 clone 下来根本编不过**（缺板级驱动）。

**建议：仓库根 = 工作区根 `C:\work2026\CardioLite\`**，让 `cardiolite-ecg/` 与
`bsp_ws_lcd5/` 保持现在的兄弟目录关系。这样现有 CMake 一行都不用改。

## 1. 入库 / 不入库 判定表

判据只有一条：**"这条东西能不能由一条命令重新生成？"** 能 → 不入。

| 内容 | 体积 | 入？ | 理由 |
|---|---|---|---|
| `cardiolite-ecg/main/`（30 个 c/h） | 693 KB | ✅ | 源码本体 |
| `cardiolite-ecg/docs/` | 576 KB | ✅ | 需求/实施计划/仿真稿，**改代码前必读的依据** |
| `bsp_ws_lcd5/` | **24 KB** | ✅ | **不入就编不过**（见 §0） |
| `lcd-bringup/`（除 build） | 小 | ✅ | 点屏验证的可复现证据 |
| `tools/*.py` `tools/*.sh` | 小 | ✅ | 构建入口 + 字库/数据生成 + MIT 验证链，全是可复用资产 |
| `test_logs/*.md` `*.log` | ~250 KB | ✅ | 7 份阶段报告是项目的**证据链**，比代码更值钱 |
| `NOW.md` | 9 KB | ✅ | 交接锚点，团队/新会话开局要读 |
| `cardiolite-ecg/sdkconfig` | 108 KB | ✅（暂） | 含 LVGL 字体、PSRAM、缓存等**全部调优**；不入则别人编出来的固件行为不同 |
| `sdkconfig.defaults` | 8 KB | ✅ | 可选，作为可读的"意图声明" |
| `dependencies.lock` | 8 KB | ✅ | 锁定 esp_lvgl_adapter 等组件的**精确版本** |
| `partitions.csv` | 4 KB | ✅ | 分区表是硬件契约 |
| **`cardiolite-ecg/build/`** | **230 MB** | ❌ | 构建产物 |
| **`managed_components/`** | **166 MB** | ❌ | 由 `idf_component.yml` 自动拉取 |
| `cardiolite-ecg/sdcard/` | 924 KB | ❌ | 拷卡用测试数据，可重新生成 |
| `mit_bih/` | 38 MB+ | ❌ | 公开数据集，`tools/mitbih_fetch.py` 可重下 |
| `ESP32-S3-Touch-LCD-5/` | 几十 MB | ❌ | 厂家资料（PDF/zip），不入代码库 |
| `.workbuddy/` | 小 | ❌ | 项目记忆与 daily log，属本地资料 |
| `tools/rpeak_ref/{bin,obj}` | 小 | ❌ | dotnet 构建产物 |
| `tools/rpeak_host/*.exe` | 小 | ❌ | 宿主编译产物 |

> 📌 关于 `sdkconfig`：严格做法是"只入 `sdkconfig.defaults`，`sdkconfig` 由构建生成"。
> 但本工程的 LVGL 字体（`MONTSERRAT_30` 等）、PSRAM 模式、缓存行大小全在 `sdkconfig` 里，
> 迁到 defaults 工作量不小且有遗漏风险。**第一阶段先入 `sdkconfig`**，保证"clone 下来
> 编出来的固件与本机一致"；后续再整理成 defaults。

## 3. 建议的执行步骤（网络恢复后）

```bash
cd C:/work2026/CardioLite

# 1) 初始化（若还没有 .git）
git init -b main

# 2) 先只 add，看清将要入库的文件清单与体积（**这一步别跳**）
git add -A
git status --short | wc -l          # 文件数，预期 60~120
git count-objects -vH               # 体积，预期 < 8 MB

# 3) 确认没有误入大文件
git ls-files | grep -E "build/|managed_components/|sdcard/|mit_bih/|\.bin$|\.elf$"

# 4) 提交
git commit -m "init: CardioLite ECG 显示终端（S0~S7 + QRS 验证工具链）"
git remote add origin https://github.com/luomcd/CardioLiteEcg.git
git push -u origin main
```

⚠ **第 2 步的体积检查是硬闸门**：如果 `count-objects` 报出几十 MB，说明 `.gitignore`
有漏，先修再提交 —— **大文件一旦进了历史，后面很难清干净**。
