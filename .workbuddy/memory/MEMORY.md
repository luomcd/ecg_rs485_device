# MEMORY.md — ecg_rs485_device 铁律

> 只放「不知道就会做错事」的条目。状态/配方见 `NOW.md`，结论见 `docs/T218~T234`。

## 1 链路真值

- 🛑🛑 **「下行丢命令」不存在**：真凶＝**SWD attach**（每次 halt 内核 ⇒ UART5 ORE ⇒ 包只剩尾巴）。**测下行禁碰 SWD。**
- 🛑 下行丢帧根因＝**UT-2211 缺 +5V**（11-09 解决）：接上后下行 100%、上行坏帧 0.000%。它**也污染上行**（1.4~2.3%，集中帧头）。
- 🛑 判双通道**只看帧长** 109 B/帧，画布切了不算。
- 🛑 算速率分母用**首末帧实测时刻差**：CH340 `read(4096)` 实测阻塞 3.49 s ⇒ 曾报 46 fps 假值。用**帧数**驱动。

## 2 协议门控（静默丢弃）

- 状态门：`0x10/0x06/0x11` **仅 STOP 态**；`0x01~0x05` 不加门。
- 长度门：`0x04/0x05/0x06` 要求 `argLen==2`。
- CRC8：poly=0x07/init=0/不反射，覆盖 `TYPE+LEN(2)+CMD+ARG`。真值 `FA/FD/C5/C2`（注释曾全是编的）。

## 3 STM32

- 🛑 UART5 RX（**PD2**）**必 `GPIO_NOPULL`**：外部分压后只有 0.7 V<0.72 ⇒ RX 恒低。**断电量电阻 >3MΩ 不能证明没下拉。**
- 🛑 读寄存器**必 `mode=hotplug`**；缺 `ErrorCallback` ⇒ 一次 FE 永久失聪。
- 🛑 **CH2 ≡ CH1**（`ads1293.c:1533` 复制）。

## 4 ESP32

- 🛑 **上电日志压到 ERROR** ⇒ 靠日志判据的验收**第一句必须 `log info`**（`restart` 会复位）。
- 🛑 **`play` 在 RS485 源下是空操作**（只置 `s_change`），但 CLI 说"波形在屏上"。先 `485-stop`。
- 🛑 **`485-start` 不等于出数据**：还要 `485-send start`(0x01)。**重启/烧录后要重来。**
- 🛑 `485-send` 未 `485-start` 时原地返回（`Δtx=0`）。
- 🛑 **非 `0x01` 合法帧会被当样本**（越界读 99 B 且 CRC 仍过）⇒ 每发一条下行＝屏上多 50 个垃圾点。规避：**先 `0x01` 再 `485-start`**。
- 🛑 SD 文件表只在开机扫一次 ⇒ 换卡必 `restart`/断电。
- 🛑 **清屏＝纯视觉**（T212 方案 B）：不改 `play`、不 `restart`、不归零位置。生产者里 `if(s_restart)` 必须在 `if(s_paused)` 之前。

## 5 HRV 判据（T218）

- 🛑 时基**只看 RR 中位数**，别看拟合斜率（多检会让斜率伪装成"偏快"）：210bpm 斜率 +1.012% vs 中位 −0.100%。
- 🛑 σ(e) 用 **σ(d2)/√6**（主）+ σ(RR)/√2（校验）；**别用去趋势残差 std**（随机游走，虚高 8 倍）。
- σ(e) ≤ **0.5 样本** = PASS；>1 = FAIL。
- 🛑 **丢帧时 σ(e) 不可信**（60bpm σ=20 vs 接 5V 后 0.30）⇒ 先确认 `crc_err`/`seq_gaps` 增量为 0。

## 6 QRS 检测器（已结案）

- 🛑 **故障强度与幅度强相关**：2mV σ=2.6、1mV σ=0.30（假 PASS）。"重放不复现"先查幅度/增益。
- ✅ 真因＝回溯 `locate_rpeak()` 覆盖不足；`fid` 修法已三层验证（90bpm 2.50→0.35、120bpm 0.22），**板端与 PC 逐峰一致**。
- 🛑 别选「加大 `filt_hist`」：所需历史随心率线性涨（40bpm≈1170），必失效。
- 🛑 主路径 `fid_delta` 不恒定（−32…+31）；存 fid 的价值是**让落点与"哪个极大触发"解耦**。
- 🛑 **σ(e) 单独不足以验收落点**，必须看**峰处原始样本值**。
- MIT 基线（T227）：主口径完整数据 **Se 99.087/+P 99.025/DER 1.889**；剔边 99.106/99.094/1.801。**两套不可混比。**
- ✅ **不做 C1/C2**：拦 6 个 FP 需 k=0.35 ⇒ 误拒 798 真拍（Se→98.37），代价≈收益 133 倍。
- ⚠ **108 号 +P 80.49%/DER 25.10%/420 FP** 属检测器本体，**不得关闭**。同类 207/104/208。
- 🛑 板上跑测：`play` 后源被抢回 FILE 必 `restart`；`rpeak rec` 只在 RS485 源；环缓满会跳样本 ⇒ 校验 `fed ≥ 0.97×secs×500`。
- 🛑 夹具 `rpeak_host` 曾无重同步（半帧就 break ⇒ 判 0 峰）：`frames=0` 先查重同步/CRC 范围。

## 7 基线乱打点（待定性）

- 🛑 **不是"无输入就自激"**（该写法作废）。条件是「**开机首个台阶小 + 有噪声**」：同一段噪声 DC 偏置 0/100/500/2000/8000 ⇒ 峰数 **46/36/1/1/1**。台阶小则 `thr≈3`、伪峰自我维持；完全恒定输入 ⇒ 0 峰。
- **MIT 验不了这类**（满负荷信号）⇒ 单列空载专项。
- 加基线预热**只有零台阶有效**（padc0：DER 1.89→1.85、首拍 26→46/48）。

## 8 环境

- 🛑 CH340-485（COM27）**必须 `p.rts=True`** 才发得出去。
- 🛑 PC 起流失败有 ASCII 回显：先看回显 → `0x10` 回读 → 重发，别归因硬件。
- ESP32 走 `485tools/idf.sh`；`flash.sh` 硬编码旧路径**别用**。STM32 走 `stm32/tools/_fw_build.py`（EIDE，产物 `<根>/build`）。
- 🛑 **就地 `open(p,'w')` 会截断**；`open(p,'wb').write(open(p,'rb').read()…)` 同样中招（先截断后读）。一律先读进变量。

## 9 LOD（导联脱落，T234 权威）

- 🛑 `has_sta=false` 时 `sta` 被写成 **0xFF**（**bit4=1**）⇒ **读 bit4 前必先判 `has_sta`**，否则"未知"读成"脱落"。
- 🛑 `lod` = **任意输入脱落**（含 IN3、含 RLD 回流断）**≠ CH1 无效**。拔 IN4 全报是手册预期，不是误报。仍**零处参与门控**（C-3 未落码）。
- 🛑 **IN4 被 RLD 输出驱动**：`0x0C=0x04` ⇒ `SELRLD=100` 把 RLD 输出**并接**到 IN4（手册 "in addition"，输出恒在 RLDOUT ⇒ **板上 IN4↔RLDOUT 不通是正常**），RLD 经 IN4→AECG N1 提供 LOD 回流 ⇒ **IN4 禁入 LOD 掩码**。`0x17=0x05` ⇒ `PACE2RLDIN=1`（RLD 正输入内部接 RLDREF）。
- 🛑 LOD **无下行命令**（`ECG_LOD_EN` 编译期）；`0x07=0x07`(IN1/2/3)、`0x08=0x01`(8 nA)。抖动＝**人碰线**（手不动 40 采样零翻转），**别当 bug 修**。
- 🛑 停流后 `has_sta` **不复位** ⇒ 屏上图标保持最后状态，不会自动回"未知"。
