```

- 🛑 **两套口径不可混比**：完整数据 Se 99.087/+P 99.025/DER 1.889；剔边 99.106/99.094/1.801。
- 🛑 **三道闸门**：`samples==902800` / `bad==0` / （mit-run/play）`dropped==0`，缺一不可。
- 🛑 **判"一致"只认逐峰序列相同**，不认 σ / 峰数 / BPM 相近。

```
