# T232 LOD 导联脱落检测：实施清单

> **日期**：2026-11-11 16:15　**性质**：任务清单与前提确认，**未动代码**
> **上游**：`T215` §4（LOD 开启评估，11-06 已定"整条关着 + 开启后基线全变"）、`T229` §18（配置不自洽）
> **一句话**：LOD 不是"打开一个宏"就完事——**但它也不是从零开始**：寄存器读路径已通、错误寄存器逐样本已在读，
> 缺的是"配起来 + 把真值送出去 + 重立基线 + 定义提示与联动"。

## 0 现状（源码级核对，2026-11-11）

| 项 | 现状 | 位置 |
|---|---|---|
| 总开关 | `#define ECG_LOD_EN 0` | `ads1293.c:11` |
| `0x06` **LOD_CN** | `0x08` ⇒ **SHDN_LOD = 1（LOD 整块关断）** | 表 `#else` 分支 |
| `0x07` **LOD_EN** | `0x00` ⇒ 六路全关 | 同上 |
| `0x08` **LOD_CURRENT** | `0x00` ⇒ **0 µA**（不注入电流） | 同上 |
| `0x09` LOD_AC_CN | `0x00` | 表 |
| `0x18` **ERROR_LOD** | **逐样本已在读** ⇒ `ecgraw.lod` | `ads1293.c:1014` |
| 二进制帧 | `lod` **不进帧**；`STATUS` bit4 **写死 0** | `ads1293.c:1221` 注释"★本步恒 0" |
| ASCII 路径 | `lod` 只进 ASCII 列（不用于判据） | `ads1293.c:1305/1342` |

**寄存器地址以本项目头文件为准**（`ads1293.h:15-30`）：
`0x01 FLEX_CH1_CN / 0x02 FLEX_CH2_CN / 0x06 LOD_CN / 0x07 LOD_EN / 0x08 LOD_CURRENT / 0x09 LOD_AC_CN / 0x18 ERROR_LOD`

> ⚠ 注意：`0x01`/`0x02` 是 **flex 通道路由**（不是 LOD）。11-11 那次 `start FAIL idx=2 reg=0x01 want=0x11 got=0x00`
> 是**欠压**导致的写失败，与 LOD 无关，已定性（T229 §13）。

⇒ 结论：**读路径已通、注入电流为 0、开关全关** ⇒ 现在 `lod=0` 是常量，**不是判据**。

## 1 必须先确认的三个前提（不定就别动手）

| # | 前提 | 为什么卡住 |
|---|---|---|
| **P-a** | **导联的连接与回路**：LOD 靠**向电极注入电流、看电压是否超阈**。用 AECG100 代替人体时，AECG 的输出阻抗很低 ⇒ **接上时不会报警（正确）**；但**"关输出"是否等于"开路"**决定 LOD 会不会误报 | 若关输出仍低阻 ⇒ 关输出不会触发 LOD（好事）；若关输出变开路 ⇒ 会误报"脱落" |
| **P-b** | **只给 1 个 bit 够不够**：`STATUS.bit4` 只能表达"有/无脱落"，**分不出 IN1/IN2/IN3 哪一路** | 分不出路数，临床提示价值大打折扣；要分就得扩协议（新 TYPE 或扩 STA） |
| **P-c** | **电流档与阈值**：T215 提议 `0x08=0xFF`（最大电流）。**最大电流会显著抬升噪声与基线**，且不同电极/皮肤阻抗差异大 | 直接上 0xFF 很可能把信号质量搞坏；建议从低档往上扫 |

## 2 任务清单（按依赖顺序）

### A 组：寄存器层（STM32）— 让 LOD 真正工作

| # | 任务 | 要点 |
|---|---|---|
| **A-1** | 确认 **LOD_CN(0x06) 的位定义**：SHDN_LOD、模式（DC/AC）、阈值档、极性 | 需要 ADS1293 手册该寄存器的位表；T215 只给了"0x00 = 开"这一个结论 |
| **A-2** | 配 **LOD_EN(0x07) 电极掩码**：本项目 CH1=I、CH2=II，导联实际接了哪几根电极？ | 掩码必须与实际接线一致，否则"该报的不报" |
| **A-3** | **电流档扫描**：`0x08` 从低到高（如 0x1F / 0x3F / 0x7F / 0xFF）逐档测"能否检出脱落 + 噪声抬升多少" | **不要直接上 0xFF**；这是本任务最需要实验的一项 |
| **A-4** | 若用 AC 模式：配 `0x09 LOD_AC_CN`（载频）并评估与 50 Hz 陷波的相互作用 | DC 模式更简单，但电极极化漂移大；要实测选型 |
| **A-5** | `ECG_LOD_EN` 置 1 时，表切到 LOD-ON 分支 | 现有的 `#if/#else` 已就位，只需换值 |

### B 组：数据层（STM32）— 把真值送出去

| # | 任务 | 要点 |
|---|---|---|
| **B-1** | `ads1293_status_byte()` **bit4 改为运行期读** `ERROR_LOD_REG` | 代码注释自己写着"必须运行期读取，不得用编译期宏"，现在恰好违反 |
| **B-2** | **防抖**：单样本 LOD 会抖（接触瞬变、运动伪迹）⇒ 连续 N 帧（如 10 帧 = 20 ms，或 100 ms）稳定才翻转 | 放在 STM32 侧更省带宽；放 ESP32 侧更容易调 |
| **B-3** | 若要"分路"：在显示帧里扩 1 字节 per-electrode 位（**协议变更**） | 依赖 P-b 拍板 |

### C 组：协议与显示（跨端）

| # | 任务 | 要点 |
|---|---|---|
| **C-1** | `STATUS.bit4` 从"恒 0"变"真值" ⇒ **协议语义变化** | 上位机若已假设恒 0，需要同步确认（WinApp 侧） |
| **C-2** | ESP32 屏上提示：图标/文字"导联脱落"（何时显示、何时消失、是否需要确认） | |
| **C-3** | **与检测器联动**：LOD 有效 ⇒ **抑制打点 / 不发布 BPM / 不喂 HRV** | 这是 T229 §17 说的"LOD 只能覆盖真脱落"那一半；与 B（幅度门）互补 |
| **C-4** | 与 **T-15** 协同：LOD 置位时 BPM 立即失效（不必等 4 s 超时） | 小改动，体验更好 |

### D 组：基线重建（**最大代价项**）

| # | 任务 | 要点 |
|---|---|---|
| **D-1** | LOD-ON 后**重测噪声底 / 基线漂移 / 幅度判据** | T215 §4.2 明确：**原有波形基线、噪声底、幅度判据全部作废** |
| **D-2** | 重跑 **B 的门限标定**（`thr_floor` 的 200 µV 是在 LOD-OFF 下标的） | 噪声抬升 ⇒ 门限可能需要上调，否则空载又会打点 |
| ~~D-3~~ | ~~重跑 MIT 48 条~~ | ❌ **本条作废（2026-11-11 16:15 自查）**：MIT 48 条是**文件回放**，样本直接喂 ESP32 检测器，**完全不经过 ADS1293**，与 LOD 无关。真正需要重测的是"经模拟前端的真实采集"（AECG 采集 / 真机），见 §7 |

### E 组：验证（LOD 专项判据）

| # | 场景 | 期望 |
|---|---|---|
| **E-1** | 电极全部贴好（AECG 接上、输出中） | `lod=0` 稳定，**不随机跳 1** |
| **E-2** | **逐根拔单个电极**（IN1 / IN2 / IN3 …） | 对应位翻转；**若只给 bit4，则至少能报"有脱落"** |
| **E-3** | 全部拔掉 | `lod=1` 且持续 |
| **E-4** | 拔掉后重新接上 | 数秒内恢复 `lod=0`（要定"恢复时间"判据） |
| **E-5** | **AECG 关输出**（导联不动） | 应**不报脱落**（关输出 ≠ 断线）——这条直接验 P-a |
| **E-6** | LOD 置位期间看检测器 | 打点应停止 / BPM 应 `--`（验 C-3） |
| **E-7** | 30 min 贴好不动 | `lod` 不误跳（与 T-3 同级的长稳） |

## 3 建议的分阶段实施（每阶段单独可验收、可回退）

| 阶段 | 内容 | 判据 | 风险 |
|---|---|---|---|
| **S1** | A-1~A-3（寄存器配起来 + 电流档扫描）+ B-1（bit4 真值） | `485-stat` 的 `lod` 能随拔线变化；同时记录噪声抬升 | **中**（改输入工作点） |
| **S2** | E-1~E-5（专项验证）+ D-1/D-2（基线重建） | 逐电极拔插正确、无随机跳；噪声与门限重新标定 | **中** |
| **S3** | C-2/C-3/C-4（屏提示 + 联动）+ B-2（防抖） | 屏上出现提示；LOD 期间不打点、BPM `--` | 低 |
| **S4** | C-1（协议/上位机确认）+ **条件性** MIT 回归（仅当 D-2 改了 `thr_floor` 或检测逻辑时） | 上位机能正确解读 bit4；若改了门限则 TP 不丢失 | 低 |
| **S5**（可选） | B-3/C-1 扩协议分路 + 分路提示 | 能指出"哪个电极脱落" | 中（协议变更） |

## 6 一句话

**LOD 的工程量不在"打开开关"，而在"选对电流档 + 重建全部基线 + 把真值送出去并定义提示"**；

建议 **先做 S1+S2 用最小改动验证"能不能可靠检出脱落"**，再决定是否继续投入 S3~S5。

## 7 LOD 对**滤波链**的影响评估（2026-11-11 16:15，猛哥提问）

> **结论先行**：**滤波器系数/结构/阶数不受影响；但算法表现受影响，必须实测**（2026-11-11 评审 §5.3 订正——不说"零影响"）。
> 系数一个字节不用改是**事实**（数字域与模拟端注入电流无关）；但"输入信号本身"变了，
> **凡是基于 LOD-OFF 实测标定的判据（噪声底、`thr_floor`、起跳/停打点）全部要重标**。

### 7.1 分层判断：谁受影响、谁不受

| 环节 | 是否受影响 | 机制 / 理由 |
|---|---|---|
| **滤波链系数 / 结构 / 阶数**（`Filter/` 的 16 节 sos、dc_block 0.05 Hz） | ❌ **不受** | 纯数字域，与模拟前端是否注入电流无关；系数不需要重算 |
| **输入直流工作点** | ✅ **大** | LOD 向电极注入电流 I，在电极-皮肤/信号源阻抗 Z 上产生 DC 台阶 ΔV = I×Z |
| **DC 台阶的滤波后果** | ✅ **关键** | 第一级是 `dc_block`（0.05 Hz 一阶，**τ = 3.18 s**）⇒ 台阶**衰减到 5% 需 ≈9.6 s、到 1% 需 ≈14.6 s** ⇒ 这段时间是**大摆幅长瞬态** |
| **int16 量程** | ✅ **危险** | 链路满量程只有 **±5 mV**。举例：I = 1 µA、Z = 10 kΩ ⇒ **ΔV = 10 mV** ⇒ **直接顶满/削顶** |
| **噪声底** | ✅ | DC 电流使极化电位不稳 ⇒ 噪声抬升（T215 §4.2 已警示"噪声抬升"） |
| **50 Hz 共模 / CMRR** | ✅ 可能 | 注入电流改变电极阻抗平衡 ⇒ 共模抑制可能变差 |
| **检测器（ESP32）** | ✅ | 上述一切都变成它的输入 ⇒ 打点数与阈值余量都受影响 |
| **B 的 `thr_floor = 200 µV`** | ✅ **必须重标** | 它的标定锚点（噪声 ±26 µV）是在 **LOD-OFF** 下测的 |
| **MIT 48 条离线回归** | ❌ **不受** | 文件回放，样本直接喂 ESP32 检测器，**不经 ADS1293** |
| **板上 `mit-run` / `play`** | ❌ 不受 | 同上（ESP32 播 SD 卡文件） |
| **AECG / 真机实时采集** | ✅ **受影响** | 唯一经过模拟前端的路径 |

### 7.2 两类影响，性质完全不同

| 类型 | 何时发生 | 表现 | 危害 |
|---|---|---|---|
| **① 开启/接触变化时的阶跃** | LOD 开启瞬间、电极重新接触瞬间 | 输入跳 ΔV，经 0.05 Hz 高通形成 **≈10 s 的指数衰减摆幅** | 可能**削顶**；这段时间检测器必然误检（B 的门限挡不住 mV 级台阶） |
| **② 稳态噪声抬升** | LOD 持续注入期间 | 噪声 RMS 升高、50 Hz 残留变化 | **吃掉 B 的门限余量**（原本噪声 26 µV vs 门限 200 µV，余量 7.7 倍；若噪声涨到 60 µV，余量只剩 3.3 倍） |

> DDR 的量化：B 的门限是"积分域"值，噪声积分随噪声幅度平方增长 ⇒ **噪声翻倍 ⇒ 积分涨 4 倍**
> ⇒ 门限的"等效 µV 余量"实际会被压缩得很厉害。这是 D-2 必须重标的量化理由。

### 7.3 还需要单独确认两个技术点（现有代码/文档没覆盖）

| # | 问题 | 为什么重要 |
|---|---|---|
| **E-a** | **LOD 注入电流的真实档位范围**（`0x08` 各档对应多少 µA） | 决定 ΔV 的量级；若最大档是几十 µA，ΔV 会到几十 mV，必然削顶 |
| **E-b** | **DC 模式 vs AC 模式的选择** | DC：持续注入 ⇒ 上述②长期存在；AC：载频可配 **6.1 Hz ~ 12.5 kHz**（手册 p6 电气特性 / §8.3.17）⇒ **是否污染 ECG 带内取决于所选载频与内部调制/同步解调方式，"低于 Nyquist 才混叠"这种说法不成立**（2026-11-11 评审 P1-5 订正），须按手册 §8.3.17~8.3.18 与实测确认 |

### 7.4 因此评估要测的量（按重要性排序）

| # | 测什么 | 方法 | 判据 |
|---|---|---|---|
| **1** | **开启瞬间的阶跃幅度与是否削顶** | `rpeak wide` 看峰邻域样本值是否顶到 ±32767；或用宽窗观测 | 若削顶 ⇒ 电流档必须调低 |
| **2** | **阶跃恢复时间** | 监测样本包络回到基线 5% 的时间 | 理论上 ≈9.6 s（0.05 Hz）；实测对照 |
| **3** | **稳态噪声 RMS**（LOD-OFF vs ON） | 空载静置下的噪声统计 | 抬升倍数决定 B 门限要不要上调 |
| **4** | **50 Hz 残留变化** | 频谱或无陷波对比 | 变差则 CMRR 受压 |
| **5** | **空载打点数**（LOD-OFF vs ON） | 与今日同法（Δpeaks/Δt） | 若 ON 后重新出现打点 ⇒ 门限必须重标 |
| **6** | **检测器在"阶跃衰减期"的误检** | 开启后 15 s 内的 peaks 计数 | 这段应视为"预热期"，可能需要抑制打点（与 A 方案呼应） |

### 7.5 对实施顺序的影响

原 S1 需要拆成两步，否则会把"阶跃瞬态"误判成"LOD 不可用"：

| 阶段 | 内容 |
|---|---|
| **S1a** | 只改 `ECG_LOD_EN=1` + `bit4` 真值，**电流档取手册最低档 `0x01`（8 nA）**→ 测 §7.4 的 1/2/3 项；后续按 §8.2 S1b 逐档上调至满足检出 |
| **S1b** | 按 S1a 结果**扫电流档**（从低往高），找到"能报脱落 + 不削顶 + 噪声可接受"的档位 |

> 🛑 **不要跳过 S1a 直接调档**：先看最坏情况（最大电流）能否接受，才能判断"降档有没有意义"。

## 8 LOD 使能之后的测试方案（评审稿）

> 本节回答"打开之后怎么测"。**前提是先补齐观测能力**（§8.1），否则测出来的只有"能不能报"，
> 测不出"代价多大"——而代价恰恰是决定 LOD 能否上产品的关键。

### 8.0 一条必须先过的合规线（安全，不是性能）

**LOD 是向电极注入电流**，这属于 IEC 60601-1 的**患者辅助电流（patient auxiliary current）**范畴，
Type CF 应用部分对直流分量有严格限值（数量级为 **≤10 µA**，具体以标准条款为准）。

| 要求 | 说明 |
|---|---|
| **在手册中查清 `0x08` 各档对应的真实 µA** | 这是选档的**硬前提**，不是"顺手看一下" |
| **任何档位都必须 ≤ 标准限值** | 若最大档（T215 提的 `0xFF`）超限 ⇒ **该档不可用于真人**，只能用于台架 |
| **台架测试（AECG100 / 电阻网络）与真人测试分开评估** | 台架可以试超限档，真人不行 |

> 🛑 因此 **S1a 用 `0xFF` 只在**"电极 → AECG100 / 电阻网络"**的台架上做，绝不在人体上做**。

### 8.1 测试前提：先补观测能力（否则"代价"测不出来）

| 观测项 | 现有手段 | 够不够 |
|---|---|---|

### 10.2 关键发现（会改变方案）

#### KF-1（**决定性**）：DC LOD 需要"右腿到地"的低阻回流

手册 §8.3.16 原文：

> *"It is important to note that the lead-off detection circuit requires a **low impedance return path from
> the right-leg electrode-to-ground**, such as a voltage reference or the RLD amplifier output.
> **Without a proper low impedance return path for the LOD currents, all enabled LOD pins will report
> a lead disconnected.**"*

⇒ **如果右腿回路不完整，所有使能的 LOD 引脚会一起报脱落**（持续误报，不是偶发）。
本项目 `{0x0C, 0x04}`（RLD_CN）把 **RLD 输出路由到 IN4**，所以**"RLD/IN4 是否形成低阻回流"直接决定 LOD 能不能用**。

**这条必须列为 P0**：它比我原先担心的"RLD 分流"更严重——不是精度问题，是**会不会全报**的问题。

#### KF-2：`0x08=0xFF` = **2.04 µA（±25%）**，合规上可行

- 手册电气特性：`IEXC` 8 nA ~ 2040 nA，**精度 ±25%**；
- Type CF 患者辅助电流的直流量级限值约 **≤10 µA** ⇒ **2.04 µA 在限内**（仍须以标准条款为准，见 §8.0）。
- ⇒ T215 提议的 `0xFF` **不是"超限的危险值"**，A/B 之前的顾虑可以撤掉；但**±25% 的容差**要在判据里留余量。

#### KF-3：`0x07=0x0F` 把 **IN4 也使能**了，而 IN4 是 RLD 输出路由点

DC 模式下 `0x0F` = `EN_LOD[3:0]` = **IN1+IN2+IN3+IN4 全部使能**。
IN4 接的是 RLD 输出（`0x0C=0x04`），**不是电极** ⇒ 对 IN4 做脱落检测没有意义，且可能与 RLD 环路冲突。

⇒ 若只检三根电极，应为 **`0x07=0x07`（IN1~IN3）**。
这一条与 KF-1 相互牵连：**IN4 既当回流点、又被当成检测点**，逻辑上打架，必须先厘清。

#### KF-4：**芯片本来就给"分路"能力** —— 6 bit 逐引脚

`ERROR_LOD[5:0]` 是**逐引脚**位（IN1..IN6），**不是**只有一个汇总位。
`0x19` 的 bit3 才是汇总位。而我们现在的问题是：`STATUS.bit4` 只传了 1 bit。

⇒ **"分路"不需要新增硬件采样，芯片已经给了 6 bit**；成本只在"帧里多带 1~2 字节 + 上位机解析"。
这直接降低了 P0-3 / P-b 的决策成本 —— **分路比原先估计的便宜得多**。

### 10.4 DC LOD 的检测原理（决定测试怎么设计）

手册 §8.3.16：

1. 通过 `EN_LOD[x]` 把 DAC 电流**注入选定输入引脚**；
2. 一个 **Schmitt 比较器**把该引脚电压与 **VDD − 0.5 V** 比较；
3. **若导联脱落** ⇒ 注入电流没有回到地的通路 ⇒ **引脚电压升向 VDD** ⇒ 比较器翻转 ⇒ 报脱落；
4. ⇒ **本质是"电压比较"，不是"阻抗测量"**。低阻信号源（AECG100）接上时引脚电压不会升 ⇒ **不报警（正确行为）**；
5. ⇒ **DC LOD 不适用于电容耦合/干电极**（§8.3.17：DC 被电容阻断）——若将来用干电极必须切 AC 模式。

## 11 T233 第二版评审的回应（2026-11-11 16:45）

### 11.1 T233 4.3 是对的，而且比它描述的更严重 —— 实现方案要改

**手册 §8.3.24 原文（line 1332）**：

> *"All error bits in the registers 0x18 through 0x1E are **latched in a high state** when an error occurs
> and will **only return to zero after being read**. … Upon read, the error bits will be cleared.
> … After being read, the error bit will be reset, **but it will return to a logic 1 if the internal alarm
> condition persists**."*

⇒ `ERROR_LOD` 是**锁存 + 读后清零**：读完就清，条件仍在则重新置 1。

**而当前代码每个样本都读一次**（`ads1293.c:1014`，在 DRDY 处理里）⇒ **锁存被逐样本消耗**。

后果（三条，都很具体）：

| # | 后果 |
|---|---|
| 1 | 单样本读到 `0` **不能**表示"没有脱落"，可能只是"刚被上一次读清掉了" |
| 2 | 任何上层要用这个值时，**锁存已经被读空** ⇒ 这也解释了为什么"逐样本读 `lod` 却不使用"等于白读 |
| 3 | 若把 `bit4` 做成"读一次当状态"，会得到**大量假阴性**（漏报） |

**⇒ 实现方案必须改（原 B-1 作废）：**

| 原方案 | 改为 |
|---|---|
| B-1：`bit4` 运行期读 `ERROR_LOD` | **B-1'**：改为**低频读（如 20 ms 一次）+ 软件锁存 + 非对称防抖** |
| 逐样本读（现状） | **从 DRDY 逐样本路径中移除**（它本身在吃锁存），改由低频任务读 |

锁存规则（建议）：

```text
raw = 读 0x18（读即清零）
if (raw != 0) { latch |= raw; }                 // 任何一位置位 ⇒ 记住
latch 的清除**不由"这次读到 0"驱动**，而由"连续 N 次读取都为 0 且已超最短保持时间"驱动
```

| `0x01` 8 nA | 0.008 µA | 0.024 µA | 0.030 µA | 417× |
| `0x3F` | 0.504 µA | 1.512 µA | 1.890 µA | 6.6× |
| `0x7F` | 1.016 µA | 3.048 µA | 3.810 µA | 3.3× |
| **`0xFF`** | 2.040 µA | **6.120 µA** | **7.650 µA** | **1.6× / 1.3×** |

⇒ **若要留 2 倍以上余量，`0x08` 不应超过 `0x7F`**（三路合计 3.05 µA）。这一条直接影响 S1b 的档位上限。

> ⚠ 前提是两个可争议点：①"三路同时注入是否按总和计入患者辅助电流"需按标准条款判定；
> ② 若某一电极脱落，该路电流失去回流，实际电流分布还会变。**这两点都要合规审查给结论。**

### 11.4 我提的一个范围问题（需拍板）

T233 P1-6 要求"每小时误报率 / 漏报率 / P50-P95 延迟"作为判据。
这些都是**产品级**指标。若把它们压到台架阶段（S1a/S1b），会出现
"**还没证明 LOD 能不能用，就要先付可靠性实验的代价**"。

建议**明确两套判据**：

| 阶段 | 判据 |
|---|---|
| **台架可行性**（S1a/S1b/S2） | 能检出 / 不削顶 / 噪声可接受 / 空载零误报（10~30 min） / 无持续全报 |
| **产品验证**（S3 + P3） | 每小时误报、漏报率、延迟分布、间歇接触、多设备多阻抗、报警系统要求 |
