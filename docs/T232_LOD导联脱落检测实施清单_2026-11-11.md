# T232 LOD 导联脱落检测：实施清单

> **日期**：2026-11-11 16:15　**性质**：任务清单与前提确认，**未动代码**
> **上游**：`T215` §4（LOD 开启评估，11-06 已定"整条关着 + 开启后基线全变"）、`T229` §18（配置不自洽）
> **一句话**：LOD 不是"打开一个宏"就完事——**但它也不是从零开始**：寄存器读路径已通、错误寄存器逐样本已在读，
> 缺的是"配起来 + 把真值送出去 + 重立基线 + 定义提示与联动"。

---

## 0 现状（源码级核对，2026-11-11）

| 项 | 现状 | 位置 |
|---|---|---|
| 总开关 | `#define ECG_LOD_EN 0` | `ads1293.c:11` |
| `0x06` **LOD_CN** | `0x08` ⇒ **SHDN_LOD = 1（LOD 整块关断）** | 表 `#else` 分支 |
| `0x07` **LOD_EN** | `0x00` ⇒ 六路全关 | 同上 |
| `0x08` **LOD_CURRENT** | `0x00` ⇒ **0 µA**（不注入电流） | 同上 |
| `0x09` LOD_AC_CN | `0x00` | 表 |
| `0x18` **ERROR_LOD** | **逐样本已在读** ⇒ `ecgraw.lod` | `ads1293.c:1014` |
| 二进制帧 | `lod` **不进帧**；`STATUS` bit4 **写死 0** | `ads1293.c:1221` 注释"★本步恒 0" |
| ASCII 路径 | `lod` 只进 ASCII 列（不用于判据） | `ads1293.c:1305/1342` |

**寄存器地址以本项目头文件为准**（`ads1293.h:15-30`）：
`0x01 FLEX_CH1_CN / 0x02 FLEX_CH2_CN / 0x06 LOD_CN / 0x07 LOD_EN / 0x08 LOD_CURRENT / 0x09 LOD_AC_CN / 0x18 ERROR_LOD`

> ⚠ 注意：`0x01`/`0x02` 是 **flex 通道路由**（不是 LOD）。11-11 那次 `start FAIL idx=2 reg=0x01 want=0x11 got=0x00`
> 是**欠压**导致的写失败，与 LOD 无关，已定性（T229 §13）。

⇒ 结论：**读路径已通、注入电流为 0、开关全关** ⇒ 现在 `lod=0` 是常量，**不是判据**。

## 1 必须先确认的三个前提（不定就别动手）

| # | 前提 | 为什么卡住 |
|---|---|---|
| **P-a** | **导联的连接与回路**：LOD 靠**向电极注入电流、看电压是否超阈**。用 AECG100 代替人体时，AECG 的输出阻抗很低 ⇒ **接上时不会报警（正确）**；但**"关输出"是否等于"开路"**决定 LOD 会不会误报 | 若关输出仍低阻 ⇒ 关输出不会触发 LOD（好事）；若关输出变开路 ⇒ 会误报"脱落" |
| **P-b** | **只给 1 个 bit 够不够**：`STATUS.bit4` 只能表达"有/无脱落"，**分不出 IN1/IN2/IN3 哪一路** | 分不出路数，临床提示价值大打折扣；要分就得扩协议（新 TYPE 或扩 STA） |
| **P-c** | **电流档与阈值**：T215 提议 `0x08=0xFF`（最大电流）。**最大电流会显著抬升噪声与基线**，且不同电极/皮肤阻抗差异大 | 直接上 0xFF 很可能把信号质量搞坏；建议从低档往上扫 |

## 2 任务清单（按依赖顺序）

### A 组：寄存器层（STM32）— 让 LOD 真正工作

| # | 任务 | 要点 |
|---|---|---|
| **A-1** | 确认 **LOD_CN(0x06) 的位定义**：SHDN_LOD、模式（DC/AC）、阈值档、极性 | 需要 ADS1293 手册该寄存器的位表；T215 只给了"0x00 = 开"这一个结论 |
| **A-2** | 配 **LOD_EN(0x07) 电极掩码**：本项目 CH1=I、CH2=II，导联实际接了哪几根电极？ | 掩码必须与实际接线一致，否则"该报的不报" |
| **A-3** | **电流档扫描**：`0x08` 从低到高（如 0x1F / 0x3F / 0x7F / 0xFF）逐档测"能否检出脱落 + 噪声抬升多少" | **不要直接上 0xFF**；这是本任务最需要实验的一项 |
| **A-4** | 若用 AC 模式：配 `0x09 LOD_AC_CN`（载频）并评估与 50 Hz 陷波的相互作用 | DC 模式更简单，但电极极化漂移大；要实测选型 |
| **A-5** | `ECG_LOD_EN` 置 1 时，表切到 LOD-ON 分支 | 现有的 `#if/#else` 已就位，只需换值 |

### B 组：数据层（STM32）— 把真值送出去

| # | 任务 | 要点 |
|---|---|---|
| **B-1** | `ads1293_status_byte()` **bit4 改为运行期读** `ERROR_LOD_REG` | 代码注释自己写着"必须运行期读取，不得用编译期宏"，现在恰好违反 |
| **B-2** | **防抖**：单样本 LOD 会抖（接触瞬变、运动伪迹）⇒ 连续 N 帧（如 10 帧 = 20 ms，或 100 ms）稳定才翻转 | 放在 STM32 侧更省带宽；放 ESP32 侧更容易调 |
| **B-3** | 若要"分路"：在显示帧里扩 1 字节 per-electrode 位（**协议变更**） | 依赖 P-b 拍板 |

### C 组：协议与显示（跨端）

| # | 任务 | 要点 |
|---|---|---|
| **C-1** | `STATUS.bit4` 从"恒 0"变"真值" ⇒ **协议语义变化** | 上位机若已假设恒 0，需要同步确认（WinApp 侧） |
| **C-2** | ESP32 屏上提示：图标/文字"导联脱落"（何时显示、何时消失、是否需要确认） | |
| **C-3** | **与检测器联动**：LOD 有效 ⇒ **抑制打点 / 不发布 BPM / 不喂 HRV** | 这是 T229 §17 说的"LOD 只能覆盖真脱落"那一半；与 B（幅度门）互补 |
| **C-4** | 与 **T-15** 协同：LOD 置位时 BPM 立即失效（不必等 4 s 超时） | 小改动，体验更好 |

### D 组：基线重建（**最大代价项**）

| # | 任务 | 要点 |
|---|---|---|
| **D-1** | LOD-ON 后**重测噪声底 / 基线漂移 / 幅度判据** | T215 §4.2 明确：**原有波形基线、噪声底、幅度判据全部作废** |
| **D-2** | 重跑 **B 的门限标定**（`thr_floor` 的 200 µV 是在 LOD-OFF 下标的） | 噪声抬升 ⇒ 门限可能需要上调，否则空载又会打点 |
| **D-3** | 重跑 **MIT 48 条**：确认 LOD-ON 后 Se/+P/DER 不劣化 | 若 LOD 注入电流污染波形，这里会立刻暴露 |

### E 组：验证（LOD 专项判据）

| # | 场景 | 期望 |
|---|---|---|
| **E-1** | 电极全部贴好（AECG 接上、输出中） | `lod=0` 稳定，**不随机跳 1** |
| **E-2** | **逐根拔单个电极**（IN1 / IN2 / IN3 …） | 对应位翻转；**若只给 bit4，则至少能报"有脱落"** |
| **E-3** | 全部拔掉 | `lod=1` 且持续 |
| **E-4** | 拔掉后重新接上 | 数秒内恢复 `lod=0`（要定"恢复时间"判据） |
| **E-5** | **AECG 关输出**（导联不动） | 应**不报脱落**（关输出 ≠ 断线）——这条直接验 P-a |
| **E-6** | LOD 置位期间看检测器 | 打点应停止 / BPM 应 `--`（验 C-3） |
| **E-7** | 30 min 贴好不动 | `lod` 不误跳（与 T-3 同级的长稳） |

## 3 建议的分阶段实施（每阶段单独可验收、可回退）

| 阶段 | 内容 | 判据 | 风险 |
|---|---|---|---|
| **S1** | A-1~A-3（寄存器配起来 + 电流档扫描）+ B-1（bit4 真值） | `485-stat` 的 `lod` 能随拔线变化；同时记录噪声抬升 | **中**（改输入工作点） |
| **S2** | E-1~E-5（专项验证）+ D-1/D-2（基线重建） | 逐电极拔插正确、无随机跳；噪声与门限重新标定 | **中** |
| **S3** | C-2/C-3/C-4（屏提示 + 联动）+ B-2（防抖） | 屏上出现提示；LOD 期间不打点、BPM `--` | 低 |
| **S4** | D-3（MIT 回归）+ C-1（协议/上位机确认） | Se/+P/DER 不劣化；上位机能正确解读 bit4 | 低 |
| **S5**（可选） | B-3/C-1 扩协议分路 + 分路提示 | 能指出"哪个电极脱落" | 中（协议变更） |

> 建议顺序：**S1 → S2 先做**（这两步才决定"LOD 到底能不能用"），**S3 让用户看得见**，
> S4 收口，S5 取决于 P-b 拍板。

## 4 与现有工作的关系（别做重复功）

| 已有结论 | 对 LOD 的影响 |
|---|---|
| **B（阈值绝对下限 200 µV）** | 解决"有信号但太弱"；**LOD 解决"根本没接"**。两者互补，B 不能替代 LOD，LOD 也不能替代 B |
| **T-15（BPM 4 s 失效）** | LOD 置位时可直接失效，比超时更及时 |
| **T215 §4.2** | 已定"LOD-ON 后基线全部作废"⇒ D 组不是可选项 |
| **T229 §18** | 记录的就是本节现状（`ECG_LOD_EN=0` 却写 LOD 寄存器、bit4 恒 0、三态 lod 全 0） |
| **11-11 三态实测** | 上电未输出/下电/悬空 三态 `lod` 全 0 —— **但那是因为 LOD 根本没开**，不能作为"LOD 无效"的证据 |

## 5 待拍板汇总

| # | 问题 | 选项 |
|---|---|---|
| 1 | **P-b：是否要"分路"提示** | (a) 只给 bit4（"有脱落"）——零协议改动；(b) 扩 per-electrode 位——能指路，需动协议 |
| 2 | **P-c：电流档** | 先扫档再定；若噪声代价过大，考虑只在"长时间无信号"时短暂注入（间歇式 LOD） |
| 3 | **DC 还是 AC 模式** | DC 简单但受极化漂移影响；AC 抗漂移但要防与陷波打架 |
| 4 | **LOD 置位时检测器行为** | (a) 仅提示，继续算；(b) 停止打点 + BPM `--`（推荐，与 C-3 一致） |
| 5 | **实施节奏** | 先 S1+S2（验证 LOD 可用性）还是连 S3 一起（一次做到用户可见） |

## 6 一句话

**LOD 的工程量不在"打开开关"，而在"选对电流档 + 重建全部基线 + 把真值送出去并定义提示"**；
其中 **D 组（基线重建）是最大代价**，因为它会把 B 在 LOD-OFF 下标定的门限与所有噪声判据全部推倒重来。
建议 **先做 S1+S2 用最小改动验证"能不能可靠检出脱落"**，再决定是否继续投入 S3~S5。
