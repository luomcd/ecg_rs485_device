## 2. 三条硬约束（决定方案形状）

1. **🛑 USB 与 UART5 物理互斥**：模组内部 `PA11≡PC12`（网络 `TXD-USB_DM`）、`PA12≡PD2`（`RXD-USB_DP`）。
   ⇒ 只能**编译期二选一**；UART 模式必须彻底不初始化 USB，否则两个推挽输出对撞。
   ⇒ 运行期切换**不做**（切过去 USB 必崩，纯风险）。
2. **🛑 发送必须异步**：`_bconvint` 是单标志（`demo.c:52-53` EXTI 置位、`demo.c:112-114` 主循环清），
   DRDY 周期 **1.172 ms**。阻塞发送 59 B @115200 = **5.122 ms** ⇒ 每帧吞掉 4.37 个 DRDY，
   **丢样 7.9%**（109 B 双通道帧 16.4%）。⇒ 用 `HAL_UART_Transmit_IT`（59 中断/帧 = 1180 次/s，
   实测开销约 **0.18% CPU**），DMA 留作后续优化（不依赖 DMAMUX 请求表，先求正确）。
3. **⚠ 电平**：Moon 脚直出 1.8V；走 ST2378（SB11/SB20）后 CN9 出 **3.3V**。TTL-USB 模块接 CN9 侧。

## 5. `comm_port.c` 骨架（关键片段）

```c
static UART_HandleTypeDef huart5;
static volatile uint8_t  s_busy;          /* IT 发送中 */
volatile uint32_t comm_tx_frames, comm_tx_drops;

void comm_init(void)
{
#if ECG_COMM_PORT == ECG_COMM_PORT_UART5
    __HAL_RCC_GPIOC_CLK_ENABLE();
    __HAL_RCC_GPIOD_CLK_ENABLE();
    __HAL_RCC_UART5_CLK_ENABLE();

    GPIO_InitTypeDef g = {0};
    g.Mode = GPIO_MODE_AF_PP; g.Pull = GPIO_PULLUP;
    g.Speed = GPIO_SPEED_FREQ_HIGH; g.Alternate = GPIO_AF8_UART5;
    g.Pin = GPIO_PIN_12; HAL_GPIO_Init(GPIOC, &g);   /* UART5_TX */
    g.Pin = GPIO_PIN_2;  HAL_GPIO_Init(GPIOD, &g);   /* UART5_RX */

    huart5.Instance = UART5;
    huart5.Init.BaudRate = 115200;  huart5.Init.WordLength = UART_WORDLENGTH_8B;
    huart5.Init.StopBits = UART_STOPBITS_1; huart5.Init.Parity = UART_PARITY_NONE;
    huart5.Init.Mode = UART_MODE_TX_RX;     /* 只焊 SB20 时 RX 也配，不影响 */
    huart5.Init.HwFlowCtl = UART_HWCONTROL_NONE;
    huart5.Init.OverSampling = UART_OVERSAMPLING_16;
    HAL_UART_Init(&huart5);
    __HAL_UART_ENABLE_IT(&huart5, UART_IT_TC);   /* 取决于 HAL 版本，按实际调整 */
#endif
}

int comm_send(const uint8_t *p, uint16_t n)
{
#if ECG_COMM_PORT == ECG_COMM_PORT_UART5
    if (s_busy) { comm_tx_drops++; return -1; }   /* 非阻塞丢帧，与 CDC 同语义 */
    s_busy = 1; comm_tx_frames++;
    return HAL_UART_Transmit_IT(&huart5, (uint8_t *)p, n);
#else
    return CDC_Transmit_FS((uint8_t *)p, n);
#endif
}

void HAL_UART_TxCpltCallback(UART_HandleTypeDef *h)
{ if (h->Instance == UART5) s_busy = 0; }
```

## 6. 验收判据（判据全部落在 **ESP32 接收端**，不依赖板侧回读）

| 关 | 动作 | 判据 |
|---|---|---|
| **A. 物理通路** | 上电；PC 旁听（`s9a_link_check.py --from-port COMx --passive`）或直接看 ESP32 | CN9.2 空闲高 = 3.3V；旁听端能切出 `AA 55 01 35` 帧头 |
| **B. 帧完整** | 跑 20 s | ESP32 `485-stat`：`frames ≈ 400`（±1）、`crc_err = 0`、`rx_bytes = 59×frames` |
| **C. 长稳** | 跑 90 s | `frames ≈ 1800`（±2）；无断流；ESP32 屏上波形连续无台阶 |
| **D. 数据逐位一致** | 同一份输入，分别用 `ECG_COMM_PORT_USB` / `UART5` 各抓 20 s | 两路帧数、每帧 59 B、CRC 全对；**样本序列逐位相同**（`cmp` 二进制流） |

- 🛑 **不做心跳串**（2026-11-03 猛哥定：目标是 ESP32 真机，观测点放接收端）。
- 🛑 关 D 是唯一能证明“只换了传输层”的判据，**不能省**（USB 模式仍可切回，见 §7）。
- ⚠ 板侧计数器（`tx_frames/tx_drops`）不做命令入口，用 ST-LINK 在线 watch 读——只在链路丢帧时用来区分“板子没发”与“链路丢了”。
