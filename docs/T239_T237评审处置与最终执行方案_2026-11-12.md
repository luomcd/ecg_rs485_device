### 1.2 P0-2 的理由订正 + 简化

`f2` 的问题不是"函数返回时失效"，而是：它声明在 `if(queue_len(&EcgQueueRaw)>=1){ … return; }` 块内，
而打包在**下一次调用**的另一个块，且打的是**往前 25 个样本**的批次 ⇒ 局部量**结构上带不过去**。

T238 建议"853 用 `codes_to_lsb(f2)`、500 用 `out2` 输出"两条分别写。
**实际上两者单位都是 int16 LSB**（`ecg_out_f32_process` 内部就含 `codes_to_lsb`）⇒
`ch2_out` 一个字段、两种模式都存 LSB，打包时**统一一句，不必按 `_braw853` 分支**。

## 2 我补的 3 条（T238 未覆盖）

### N1｜阶段①大概率看到 CH2 接近平线 —— 这是**预期**，不是故障

当前 CH2 = `N2 − LA`：

- 若 AECG100 的 N2 与 LA 共参考 ⇒ 差分交流成分很小 ⇒ 屏上一条低幅起伏；
- 若不共参考 ⇒ 直流差撞 `ECG_RESTORE_TH_CODES`（50 mV ≈ 445,633 codes）⇒ CH2 **长期停在伪迹空白，输出恒 0**。

🛑 **必须先立区分判据**：`raw853 on` 看 ASCII **列⑦（`ecgraw2` 原始码）** 有没有在动。
**原始码在动而滤波值恒 0 ⇒ 是被空白态吃掉，不是链路没通。** 不写清这条，看到平线必误判成"CH2 没接上"。

### N2｜"两路独立伪迹判定"挡不住读码坏

CH1/CH2 出自**同一次** `read_reginc(0x37, 6)` 突发（`ads1293.c:591~613`）⇒ 坏码**两路同时坏**
（T196p 记录的 3,758,251 那类：列② 与列⑦ 同出处、同时异常）。
⇒ 独立判定的真实收益只是"两路信号本身不同"，**不能指望它隔离读码故障**。文档两件事分开写。

### N3｜`ecgraw` 故意不做 24-bit 符号扩展，CH2 必须照抄

`ads1293.c:604-607` 的符号扩展被**注释保留**（注释明写"改它等于改标定"）。
CH2 若擅自做 `0xFF000000` 扩展，两路量纲差 2²³，dc_block 的差分基准直接错。
⇒ 步 2 落码时 CH2 **一行不动地沿用** `ecgraw2` 的原始 0~0xFFFFFF 口径。

## 3 升级为 P0：`dtcycles` 位宽不够

- `ecg_filter_t.dtcycles` 是 **`uint16_t`**（`ads1293.h:120`）；
- 80 MHz 下 65535 cyc = **819 µs**，而 DRDY 周期 1172 µs ≈ **93.7 kcyc** ⇒ **字段装不下一个样本周期**；
- 现状 CH1 全链实测 ≈ **11,650 cyc ≈ 146 µs**（`fast_restore_snippet.c:142` 注释），加倍 ≈ 290 µs 仍在范围内，
  但 T238 P1-4 要求记 `total / max / overrun` —— **一旦某次尖峰超 819 µs，字段静默回绕，看起来"很快"**，
  正好把要验的东西藏起来。

**处置**：`dtcycles` 改 `uint32_t`，**零成本**（正好吃掉 offset 6-7 的 pad，`sizeof` 仍 32 B）。
`dtcycles` 口径**保持 CH1-only**（ASCII 列⑥ 与历史数据可比）；总耗时不进结构体，另用 2 个 file-static
（`s_dt_max_total` / `s_dt_over`）＋ 一条临时 ASCII `test cpustat` 回显。

⚠ 连带检查：列⑥ 是 `%05u`，值 23,300 仍是 5 字符，ascii-2 的"恒 18 B"不受影响；
若真超 99,999（1.25 ms）会变 6 字符，由既有 `len` 护栏截行，不会越界。

## 4 最终执行方案

### 4.1 步 1：只重构 CH1（含 A/B 双跑验证）

**改什么**

1. `Filter/fast_restore_snippet.c`：把 4 个 static（`s_base/s_seen/s_blank/s_hold`）+ `s_startup` + `g_dc` + `f64`
   打包成 `ecg_restore_ctx`，实现 `ecg_restore_ctx_init()` / `ecg_restore_ctx_process()`；
   保留 `ecg_restore_start()` / `ecg_restore_process()` 两个兼容包装，**CH1 调用点签名不变**。
2. `Filter/fast_restore_snippet.c` 新增 `ecg_restore_set_notch/set_mode/get_*()`，同时作用于 CH1（此时只有一路）。
3. `ads1293.c` / `vcomcmd.c`：10 个读点 / 6 个写点改走上面这组入口（这是 P1-3 的前置）。

**怎么证明逐位不变（替代 T238 P0-4）**

> 不用 MIT 回放：它只能比峰序列，且从 ASCII 输出行**重建不出完整 853 输入流**
> （500 模式下不产生输出的原始样本被丢弃）。

用**同固件 A/B 双跑**，验证版临时编入：

```c
/* T237_AB_VERIFY：旧实现原样保留为参照（自己的 g_dc_ref/f64_ref + 5 个 static） */
double ecg_restore_process_legacy(int32_t x);

/* ads1293.c 调用点 */
#if T237_AB_VERIFY
    double a = ecg_restore_process_legacy(ecgfilter.ecgraw);
    double b = ecg_restore_process(ecgfilter.ecgraw);
    g_ab_total++;
    if (memcmp(&a, &b, sizeof a) != 0) g_ab_mismatch++;
    ecgfilter.filterraw = b;
#else
    ecgfilter.filterraw = ecg_restore_process(ecgfilter.ecgraw);
#endif
```

- `notch/mode` 设置同时作用于两实例（`set_notch` 里一并写）⇒ 状态严格对齐；
- 跑 1~2 min，**中途主动覆盖**：`test notch on/off`、`test mode diag/mon`、`raw853 on/off`、STOP→START（复位/静默窗）、
  以及一次拔线触发的伪迹空白；
- 结果用临时 `test abstat` 回显 `ab: total=<n> mismatch=<m>`，**要求 `mismatch == 0` 且 `total ≥ 100000`**；
- 过完删掉 `#if T237_AB_VERIFY` 整段与 `test abstat`，**单独一个 commit**（不带验证代码）。

**为什么够了**：两路吃的是**同一输入流、同一状态迁移**，`filterraw` 是唯一对外产物；
`dsrateraw` 由 `out`（未改动）+ `filterraw` 唯一决定 ⇒ 逐位不变传递到帧字节。
`raw853` 路径直接取 `filterraw` 做 `codes_to_lsb`，同样传递。

## 5 `ecg_filter_t` 最终布局（含两处"零成本"改动）

```c
typedef struct {
    uint32_t idxraw;      /* @0    4                     */
    uint32_t dtcycles;    /* @4    4  ← 原 uint16，吃原 pad @6-7 */
    int32_t  ecgraw;      /* @8    4                     */
    uint32_t idxfilter;   /* @12   4                     */
    int16_t  dsrateraw;   /* @16   2                     */
    int16_t  ch2_out;     /* @18   2  ← 吃原 pad @18-19，LSB，两模式统一 */
    int32_t  ecgraw2;     /* @20   4                     */
    double   filterraw;   /* @24   8                     */
} ecg_filter_t;                     /* sizeof = 32，与改动前一致 */
```

⚠ 校验方式沿用工程既有做法（`stm32/tools/_t125_g8_sim.py` 的 struct 解析 + offset 断言），
**不引入 `_Static_assert`**（IAR / AC6 两套工具链都得单独验，没必要）。
断言项：`sizeof==32`、`ch2_out@18`、`ecgraw2@20`、`filterraw@24`、`dtcycles@4`。
