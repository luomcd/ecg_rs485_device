# T232 评审报告：LOD 导联脱落检测实施清单

> **日期**：2026-11-11  
> **报告版本**：v3  
> **评审对象**：`T232_LOD导联脱落检测实施清单_2026-11-11.md`  
> **独立核对资料**：ADS1293 数据手册、AECG100 用户手册 v1.7.0、当前 STM32/ESP32 源码  
> **评审结论**：**可继续受控台架研究；暂不批准进入正式固件配置，禁止人体测试。**

---

## 0 v3 评审摘要

T232 最新版本相较 v2 有明显进步，已经补入：

- ADS1293 手册中的 LOD 寄存器、电流范围、错误位和 RLD 回流要求；
- `ERROR_LOD` 为锁存位、读取后清零的软件状态设计；
- 三路同时注入时的总电流核算；
- AECG100 用户手册中的端子定义；
- 现场实际 IN1~IN4 接线核对；
- 基于现场事实的 IN1/IN2 简化台架路径。

上一轮多项问题已经关闭：

- 单路与三路总电流未区分；
- 逐样本读取 LOD 会消耗锁存；
- S2-5 对 AECG 关输出采用了过强假设；
- MIT-BIH 回归是否需要已改为条件性；
- 首次实验已改为最低电流档。

但新增的现场接线核对暴露出比 LOD 本身更基础的阻断项：

1. CH1 实际极性为反相；
2. CH2 在软件中只是 CH1 副本，不是真实的导联 II；
3. IN3 接 AECG 地端，可能被 RLD 回流钉住；
4. IN4 同时作为 RLD 输出和回流连接点，板级网络仍未实测；
5. AECG N1/N2 是否内部相连尚未测量；
6. S1a 的最小配置仍有 `0x03` 与 `0x07` 两套互相冲突的建议；
7. 连续波形观测仍不足；
8. 文档上半部分仍保留已被 §11/§12 推翻的旧表述。

因此当前 T232 是有价值的调查记录，但仍不是可直接执行的施工单。

---

## 1 已独立确认的事实

### 1.1 ADS1293 寄存器与电流

ADS1293 数据手册与 T232 §10 基本一致：

| 项 | 数据手册结论 |
|---|---|
| `0x06` | `SHDN_LOD=0` 使能检测，`SELAC_LOD` 选择 DC/AC；默认关断 |
| `0x07` | DC/Analog AC 模式对应 IN1~IN6；Digital AC 对应 CH1~CH3 及相位 |
| `0x08` | 0~2.040 µA，步进8 nA，精度±25% |
| `0x09` | AC 激励分频，频率范围6.1 Hz~12.5 kHz |
| `0x18` | IN6~IN1 的逐输入 LOD 状态 |
| `0x19[3]` | LEADOFF 汇总状态 |
| `0x12[2]` | 必须置1，错误寄存器才更新 |
| RLD 回流 | 缺少低阻回流时，所有启用的 LOD 输入一起报告脱落 |

当前 `0x12=0x04`，时钟使能已满足。

### 1.2 AECG100 端子

AECG100 用户手册 p10 明确：

- `RA/R`、`LA/L` 是 ECG 仿真信号输出；
- `RL1/N1`、`RL2/N2` 是可连接到被测物接地电极的地端子；
- 没有独立的 `LL/L` 信号输出。

因此 AECG100 试验台不能直接生成真正的标准导联 II。

### 1.3 当前软件通道

源码核对确认：

- CH1 来自 IN2−IN1；
- CH2 真实 ADC 值只进入 ASCII 诊断列；
- 二进制 CH2 数据是 CH1 的逐点复制。

所以现有屏幕上的双通道不能证明 CH2 的模拟输入、导联或 LOD 状态正确。

## 2 已认可的新设计

### 2.1 `ERROR_LOD` 低频读取 + 软件锁存

手册明确错误位发生后锁存为1，读取后清零；若故障持续，还会重新置位。

当前每样本读取 `0x18` 会把硬件锁存不断消费。T232 §11.1 改为：

- 从 DRDY 逐样本路径移除 `ERROR_LOD` 读取；
- 低频读取，例如每20 ms；
- 软件按输入位锁存；
- 连续多次为零后才清除。

方向正确。这样既不会丢掉两次读取之间的短故障，也不会因为一次读到0立即误清告警。

### 2.2 总电流按三路合计核算

T232 现在区分：

```text
单路：最大 2.040 µA，±25%
三路：标称 6.12 µA，最坏 7.65 µA
```

并建议若需要约2倍安全余量，不应超过 `0x7F`。

这个修正正确。实际是否三路叠加、如何计入患者辅助电流仍要合规确认。

### 2.3 IN4 不得误启用

当前 `0x07=0x0F` 会同时使能 IN1~IN4。IN4是 RLD 输出路由点，不应作为普通电极检测输入。

使用 `0x07=0x03` 只测 IN1/IN2，是当前现场拓扑下更小、更能解释的实验，适合先验证 CH1 路径。

### 2.4 阶段判据分层

T232 §11.4 将：

- 台架可行性；
- 产品级可靠性；

分开是合理的。台架阶段先回答：

- 能不能报；
- 是否削顶；
- 噪声是否可接受；
- 是否有持续全报；

产品阶段再定义误报率、漏报率、延迟分布和多设备测试。

## 3 P0 级阻断项

### P0-1 先冻结并纠正“实际通道语义”

现场接线核对得出：

```text
CH1 = AECG_RA − AECG_LA = −(LA − RA)
```

因此 CH1 是反相的类导联 I 信号，不是文档原先假设的方向。

同时：

```text
CH2 真实 ADC = 地 − AECG_LA
软件 CH2     = CH1 副本
```

所以目前不能继续在任何产品结论中写：

- CH1 = Lead I；
- CH2 = Lead II；
- 双通道已真实工作；
- IN3 脱落会直接影响当前 QRS。

这是独立于 LOD 的数据语义缺陷。必须先把：

- CH1 极性；
- CH2 是否启用真实采集；
- LIN/IN1~IN3 与物理电极；
- QRS 实际使用的通道；

写入冻结配置，再定义 LOD 掩码和通道门控。

### P0-2 N1/N2、IN3、IN4 与 RLD 回流仍未实测

AECG 手册只说明 N1、N2 都能作为接地端，没有保证二者内部相连。

T232 假设若 N1/N2 相连，则：

```text
RLD → IN4 → N1 →（可能）→ N2 → IN3
```

从而 IN3 可能被 RLD 钉住，LOD 永不翻转。这个推断合理，但尚未因此成为事实。

必须实测：

1. AECG 断电状态下 N1↔N2 通断；
2. 上电运行状态下 IN3 对模拟地的电压和源阻抗；
3. IN4 是否连接到实际 RLD 回流节点；
4. 拔 N1 时 IN1/IN2 的 LOD 是否如数据手册所述一起置位；
5. 使用电阻网络时是否复制了同样的回流拓扑。

在这些测试完成前，不能把 IN3 的 LOD 结果纳入产品判据。

### P0-3 患者辅助电流仍需精确合规

当前 T233 不再要求“重新计算总电流”，因为 T232 已给出 3 路合计。

仍未完成的是：

- 适用标准版本和条款；
- 该总和是否按患者辅助电流计入；
- 正常和单一故障状态的限值；
- DC、AC 和脉冲条件的差异；
- 不同 VDD、温度和电流容差下的最坏值；
- 导联脱落开路时电流如何重新分配。

在这些确认前：

- 3路 × 2.55 µA = 7.65 µA 只能是保守工程估计；
- 不能宣称“合规可行”；
- 不能进行人体测试。

### P0-4 连续观测能力仍不足

`rpeak wide` 仅提供峰附近 ±3 样本；`rpeak diag` 提供的是检测器内部量。

要评估 LOD 的代价，必须有连续数据：

- 台阶幅度；
- 连续削顶；
- 峰间饱和；
- 0.05 Hz 恢复曲线；
- 输入 RMS/PSD；
- 50 Hz 残留；
- CMRR；
- 丢帧和跳样本。

至少增加：

- 连续原始/滤波波形导出；或
- 固件内的 RMS、min/max、饱和计数、最长饱和长度、50 Hz 能量。

仅依靠 T-prep-1 不足以通过科学评审。

### P0-5 S1a 配置仍有冲突

当前文档存在两套起步配置：

- §8.2 S1a：`0x07=0x07`；
- §12.7 简化方案：`0x07=0x03`。

结合现场接线，建议台架首轮采用：

```c
LOD_CN      = 0x00;  /* DC, SHDN_LOD=0 */
LOD_EN      = 0x03;  /* 仅 IN1/IN2，对应当前真实 CH1 */
LOD_CURRENT = 0x01;  /* 8 nA */
LOD_AC_CN   = 0x00;
```

但即使这样，也不是量产配置：必须先完成 N1/N2 回流通断测量。

此外，源码 `ECG_LOD_EN=1` 分支仍是 `0x07=0x0F`、`0x08=0xFF`。
因此“只改宏”仍会得到错误配置，施工步骤必须列出所有实际表项改动。

## 4 P1 级问题

### P1-1 软件锁存方案需要正式状态机

T232 已提出低频读取和软件锁存，但还应补全：

```text
每输入 raw 故障
每输入 latched 故障
每通道 derived invalid
告警保持
恢复稳定
```

建议规则：

- 读到非零：按位锁存；
- 读到零：只在持续为零超过保持和恢复时间后清除；
- 报警建立和清除采用不同阈值；
- 重新接通后等待基于时间的 ready；
- 清屏不应清除锁存；
- START/STOP 和复位要定义是否保留；
- 每个 STATUS 帧必须对应明确的时间窗口。

### P1-2 文档上半部分仍有旧结论

§12 已证明旧通道描述不成立，但前面仍保留：

- A-2 的 “CH1=I、CH2=II”；
- E-5 的 “AECG 关输出应不报”；
- §8.4 的绝对“不置位”；
- §9 的 “CH1=I / CH2=II”；
- AC 检查表中的 “载频 ≥ Nyquist”；
- “S1a 最大电流/最坏情况”；
- §8.0 的 “S1a 用 0xFF”；
- “KF-2 合规上可行”。

这些必须统一到 §10~§12 的最新结论，否则执行者会按旧段落操作。

### P1-3 最小可用台架判据

建议首轮只验证 CH1：

| 条件 | 期望 |
|---|---|
| 正常 LA/RA 连接 | `0x18=0x00` |
| 拔 IN1/LA | `bit0=1` |
| 拔 IN2/RA | `bit1=1` |
| 断 RLD/IN4回流 | `bit0|bit1=0x03` |
| AECG 关闭但回流仍完整 | `0x00` |
| AECG 关闭且回流断开 | 允许报告脱落 |

这不证明完整三导联 LOD，只证明当前单通道数据路径可用。

### P1-4 电流档扫描

- 从 `0x01=8 nA` 开始；
- 每次只改一个变量；
- 每一档记录 IN1/IN2 原始 LOD；
- 记录报警、恢复、噪声和削顶；
- 不允许在人体上递增到高风险档；
- 不把 `0x7F` 或 `0xFF` 作为台架初始档。

### P1-5 LOD 与检测器的联动应依据通道有效性

当前真实 QRS 只使用 CH1。故首轮门控应该是：

```text
CH1 invalid = IN1 off OR IN2 off
```

IN3 的 LOD 和软件 CH2 暂不能直接决定产品 QRS 门控，除非先解决真实 CH2 采集。

### P1-6 状态位与协议

芯片提供 `ERROR_LOD[5:0]`，但当前二进制帧只有一个 STATUS bit4。

必须先决定：

- bit4 是任意输入脱落还是所选通道无效；
- 是否扩展逐输入字节；
- 扩展字节属于显示帧还是独立诊断帧；
- WinApp 和现有上位机如何处理；
- 未实现分路时是否显示明确的简化状态。

## 5 科学验收矩阵

### 5.1 台架可行性

| 项 | 判据 |
|---|---|
| RLD/IN4回流 | 有明确低阻路径 |
| N1/N2拓扑 | 已实测并记录 |
| IN1/IN2单路断开 | 对应 bit 稳定置位 |
| RLD回流断开 | IN1/IN2全报，行为可解释 |
| AECG关闭但回路完整 | 不报警 |
| 8 nA~选定档电流 | 能检出且不削顶 |
| 空载持续10~30 min | 无持续全报，无异常峰 |
| 连续波形 | 可导出或完整统计 |

### 5.2 产品验证

| 项 | 判据 |
|---|---|
| 误报/漏报率 | 由产品要求定义 |
| 报警延迟 | P50/P95/max |
| 恢复延迟 | P50/P95/max |
| 电极阻抗 | 正常、高阻、间歇、悬空 |

## 6 最终评审意见

### 已关闭

- ADS1293 基础寄存器事实；
- LOD电流范围和精度；
- 逐输入错误状态；
- RLD回流警告的识别；
- 总电流核算；
- `ERROR_LOD` 读后清零问题的识别；
- S2-5的回路完整性条件；
- MIT-BIH条件性回归；
- 首次实验从低档开始。

### 仍阻断

- AECG N1/N2、IN3、IN4/RLD拓扑未实测；
- CH1极性反相、CH2为复制通道，数据语义尚未冻结；
- 3路总电流的标准合规性未确认；
- S1a仍存在 `0x03/0x07` 配置冲突；
- 软件低占空比读取和锁存尚未形成正式状态机；
- 连续波形、削顶和噪声观测不足；
- 文档前部旧结论未同步清理；
- 人体测试仍被安全边界阻断。

### 最终结论

> **T232 的最新版本已经从“是否掌握 LOD 原理”推进到“实际电路和通道是否支持 LOD”。**
>
> **当前最重要的不是打开 LOD，而是先冻结真实通道语义并实测 RLD/N1/N2 回流。**
>
> **在这些事实闭环前，只能做不接人体的受控台架研究，不能进入正式固件配置或人体测试。**
